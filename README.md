# Engineering Book Store

Responsive front-end student project using HTML5, CSS3 and vanilla JavaScript.

## Files
- `homepage.html`: landing page and department navigation
- `register.html`: registration and generated Login ID
- `login.html`: demo login
- `catalogue.html`: two-book catalogue and cart
- `cse.html`: textbook selection and total calculation
- `ece.html`, `eee.html`, `mech.html`: department subject lists
- `styles.css`: shared responsive styling
- `app.js`: registration, demo login, cart and price calculation

## Run locally
Download/clone the repository and open `homepage.html` in a modern browser. No build tools are needed.

## Important limitation
This is an educational front-end demonstration. User and cart data are stored in browser `localStorage`. There is no backend, database, secure password storage, payment gateway or real order processing. Do not use real passwords or personal data.

## Deploy with GitHub Pages
1. Push all project files to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. Wait for GitHub Pages to publish; copy the URL shown there.
6. Test navigation, registration, login and cart on the public URL.

## Technologies
HTML5 · CSS3 · JavaScript · Browser localStorage
