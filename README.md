# Engineering Book Store

A simple **Web Technology laboratory project** developed as part of my undergraduate coursework.

The project demonstrates a basic engineering book store interface using HTML, CSS and JavaScript.

## 🌐 Live Website

**[View Engineering Book Store](https://abhiramreddy2603.github.io/Web-Technology-Assignment/homepage.html)**


## Features

- Homepage with department navigation
- Registration form with a generated demo Login ID
- Demo login
- Book catalogue with a basic cart
- CSE textbook selection and price calculation
- Department-wise subject lists for CSE, ECE, EEE and Mechanical

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser `localStorage`

## Run Locally

1. Clone or download this repository.
2. Open `homepage.html` in a modern web browser.
3. No installation or build tools are required.

## Project Files

| File | Purpose |
|---|---|
| `homepage.html` | Home page and department navigation |
| `register.html` | Demo registration |
| `login.html` | Demo login |
| `catalogue.html` | Book catalogue and cart |
| `cse.html` | CSE textbook selection and price calculation |
| `ece.html`, `eee.html`, `mech.html` | Department subject lists |
| `styles.css` | Shared page styling |
| `app.js` | JavaScript functionality |

## Note

This is a small academic front-end project. It does not include a backend, database, secure authentication, payment processing or real order management. Demo account and cart information are stored in the browser using `localStorage`. Please do not enter real passwords or sensitive personal information.
